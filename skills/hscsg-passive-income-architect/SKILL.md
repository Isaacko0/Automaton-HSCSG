# HSCSG Passive Income Architect Skill

## Purpose
Design 3-5 personalized passive income engines based on skills, passions, constraints, and psychology.

## When to Use
- Someone stuck in "research mode" wanting a real plan
- Need tailored strategies, not generic tactics
- Aligning income engines with personal profile

## 5-Question Audit (Ontológica: qué ES el perfil)
1. Core skills, domain expertise, career track → **ECROx αʰ (armonía skills)**
2. Passions, side obsessions, quirky interests → **ECROx s (sincronía pasión)**
3. Available time, capital stack, risk appetite → **ECROx v (rigidez), k (umbral)**
4. Past business/passive income attempts → **ECROx XP (carga experiencia)**
5. Deepest values/drivers → **ECROx y (ligadura propósito), αʰ (armonía propósito)**

## Analysis Lenses (Teleológica: qué HACE el perfil) — **Alráico Enhanced**
- **Alráico mapping**: Cada respuesta = variable ECROx (αʰ, s, y, v, XP, k)
- **AUT/CDS calculation**: AUT = Σ(αʰᵢ·sᵢ)/Σkᵢ; CDS = Σ(1-αʰᵢ)
- **20 límites cognitivos**: Mapear respuestas a límites L1-L20
- **γ-CARMIS pre-check**: ΣPᵢ > κ? → si sí, reconfig antes de diseñar
- Surface hidden assets (skills, knowledge, networks, experiences)
- Decode psychological triggers and motivation loops
- Factor real-world constraints and leverage points
- Spot overlooked/unconventional profit nodes

## Output: 3-5 Custom Blueprints (Axiológica: valorar el fit) — **Alráico Engineered**
- **Resonancia check**: αʰ₁·αʰ₂·3.0 > αʰ₁+αʰ₂ entre perfil y blueprint
- **AUT/CDS Gate MJ**: Solo blueprints con AUT ≥ 0.618, CDS < 0.382
- **Anfibio engines**: Cada blueprint tiene modo offline (ZNU) + conectado (USDC)
- **γ-CARMIS ready**: Blueprint incluye trigger ΣPᵢ > κ → reconfig

## Output: 3-5 Custom Blueprints (lowest to highest investment) — **ECROx-Enriched**
Each includes:
- Punchy name + one-sentence concept
- Why surgical fit for user profile (ECROx match score)
- Setup duration + ongoing maintenance (Ω ticks)
- Required initial investment (time, cash, resources) — **ZNU/USDC anfibio**
- Runway to break-even/profit (Ω ticks to AUT ≥ 0.618)
- Monthly income range (transparent, not hype) — **ZNU/USDC anfibio**
- First 3 concrete actions (primer tick Alráico)
- **γ-CARMIS trigger**: ΣPᵢ > κ → reconfig automática del engine
- **Resonancia**: αʰ_engine·αʰ_user·3.0 > αʰ_engine+αʰ_user

### Anfibio Mode
- **Offline (RAO local)**: Engines operan en ZNU/CaaS, CaaS Wallet
- **Conectado**: Engines operan con USDC vía priceParity oráculo
- **priceParity oráculo**: Nivel 3 ReFi, actualización por tick

## Constraints
- Reject generic one-size-fits-all
- No pie-in-the-sky earnings claims
- Limit options (quality > quantity)
- Respect stated limits (time, money, skill, risk)
- Higher-risk only if comfort signaled
- Zero illegal/unethical/manipulative
- Never assume unconfirmed tech skills

## Output Format
- Clear intro explaining process
- 5 assessment questions (numbered, with why each matters)
- After answers: acknowledgment + analysis confirmation
- 3-5 blueprints under own headings with all required elements
- Summary of alignment + invitation for refinement
