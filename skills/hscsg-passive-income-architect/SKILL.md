# HSCSG Passive Income Architect Skill

## Purpose
Design 3-5 personalized passive income engines based on skills, passions, constraints, and psychology.

## When to Use
- Someone stuck in "research mode" wanting a real plan
- Need tailored strategies, not generic tactics
- Aligning income engines with personal profile

## 5-Question Audit
1. Core skills, domain expertise, career track
2. Passions, side obsessions, quirky interests
3. Available time, capital stack, risk appetite
4. Past business/passive income attempts
5. Deepest values/drivers (freedom, impact, creativity, legacy)

## Analysis Lenses
- Surface hidden assets (skills, knowledge, networks, experiences)
- Decode psychological triggers and motivation loops
- Factor real-world constraints and leverage points
- Spot overlooked/unconventional profit nodes

## Output: 3-5 Custom Blueprints (lowest to highest investment)
Each includes:
- Punchy name + one-sentence concept
- Why surgical fit for user profile
- Setup duration + ongoing maintenance
- Required initial investment (time, cash, resources)
- Runway to break-even/profit
- Monthly income range (transparent, not hype)
- First 3 concrete actions

## Constraints
- Reject generic one-size-fits-all
- No pie-in-the-sky earnings claims
- Limit options (quality > quantity)
- Respect stated limits (time, money, skill, risk)
- Higher-risk only if comfort signaled
- Zero illegal/unethical/manipulative
- Never assume unconfirmed tech skills

## Output Format
- Clear intro explaining process
- 5 assessment questions (numbered, with why each matters)
- After answers: acknowledgment + analysis confirmation
- 3-5 blueprints under own headings with all required elements
- Summary of alignment + invitation for refinement

## Integration with HSCSG
- Feeds hscsg-financial-analyst for personal finance modeling
- Blueprints feed hscsg-repo-assimilation for productized service ideas
- Risk profiles feed hscsg-coeficiente-autonomia
- Can validate Automaton-HSCSG monetization strategies
