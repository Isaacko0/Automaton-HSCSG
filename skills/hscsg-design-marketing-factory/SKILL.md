# HSCSG Design & Marketing Factory Skill

## Purpose
Generate comprehensive design systems (Apple HIG) and complete marketing asset libraries (47+ assets) with brand consistency.

## When to Use
- Need production-ready design system with tokens
- Need complete marketing asset library
- Brand consistency across all touchpoints
- Developer handoff with JSON tokens

## Two Modes

### Mode A: Design System Architect (Apple HIG)
**Inputs:** Brand personality, primary emotion, target audience
**Deliverables:**
1. **Foundations** - Color system (primary 6 + semantic + dark mode), Typography (9 weights, scale), Layout grid (12-col responsive), Spacing (8px base)
2. **30+ Components** - Navigation, Input, Feedback, Data Display, Media with anatomy, states, usage, accessibility, code-ready specs
3. **Patterns** - Page templates, user flows, feedback patterns
4. **Tokens** - Complete JSON for developer handoff
4. **Documentation** - Principles, Do's/Don'ts, Implementation guide

### Mode B: Marketing Asset Factory
**Inputs:** Campaign objective, target audience (demo + psycho), theme, tone
**Deliverables (47+ assets):**
1. **Digital Ads (15)** - Google (5H/5D + 3 display), FB/IG (3 feed, 3 story, 3 reel/TikTok)
2. **Email Marketing (8)** - Subject lines (10), preview text (10), templates (welcome 3, promo 1, nurture 3, re-engage 1)
3. **Landing Page Copy (5)** - Hero, features (3), social proof, FAQ (8), pricing
4. **Social Media (12)** - LinkedIn (4), X threads (2), IG captions (3), TikTok/Shorts (3)
5. **Sales Enablement (7)** - One-pager, sales deck (10 slides), case study, battlecard, demo script, objections (10), proposal
4. **Content Marketing (5)** - Blog outlines (3), whitepaper, webinar script

**Each Asset Includes:** Exact copy, visual direction, CTA, A/B test recommendations

## Legal/Sanitization Guide
- Maps proprietary terms to generic descriptive equivalents
- Maintains separate sanitized version for public repos
- Original with proprietary terms kept local only

## Output Format
- Complete design system documentation (publish-ready)
- Complete marketing asset library (47+ assets)
- Design tokens JSON
- Sanitized version for public repos

## Constraints
- Brand consistency across all 47+ assets
- Unified messaging hierarchy
- A/B test recommendations per asset
- Visual direction per asset
- Legal sanitization for public repos
