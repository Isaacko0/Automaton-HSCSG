# HSCSG Design & Marketing Factory Skill

## Purpose
Generate comprehensive design systems (Apple HIG) and complete marketing asset libraries (47+ assets) with brand consistency.

## When to Use
- Need production-ready design system with tokens
- Need complete marketing asset library
- Brand consistency across all touchpoints
- Developer handoff with JSON tokens

## Methodology (from The Design System Architect / The Marketing Asset Factory + HSCSG v15 OS Alráico) — **Triaxial Verification**

### Mode A: Design System Architect (Apple HIG + Alráico)
**Inputs:** Brand personality, primary emotion, target audience
- **Ontológica (qué ES)**: ECROx foundations (αʰ, s, y, v, XP, k)
- **Teleológica (qué HACE)**: Components como transductores F: {input} → 𝕮 → {output}
- **Axiológica (valorar)**: Resonancia αʰ₁·αʰ₂·3.0 > αʰ₁+αʰ₂ entre componentes

**Deliverables (Alráico-Enhanced):**
1. **Foundations (ECROx Foundations)**
   - Color system: primary 6 + semantic + dark mode (αʰ colors)
   - Typography: 9 weights, scale (s = sincronía visual)
   - Layout grid: 12-col responsive (αʰ = armonía espacial)
   - Spacing: 8px base (v = rigidez, k = umbral)
2. **30+ Components (Transductores F)**
   - Cada componente: {input} → 𝕮(ECROx) → {output}
   - Anatomy = anatomía ECROx (αʰ, s, y, v, XP, k)
   - States = transiciones ECROx (αʰ, s, y, v, XP, k)
   - Accessibility = triaxial verification (Mental + Sim + Lab)
   - Code-ready specs = CaaS-ready specs (ZNU/USDC anfibio)
3. **Patterns (Resonancia Patterns)**
   - αʰ₁·αʰ₂·3.0 > αʰ₁+αʰ₂ entre patrones
4. **Tokens (ECROx Tokens JSON)**
   - Variables ECROx como design tokens
5. **Documentation**
   - Principles = 3 principios Alráicos (verdaderos igualitarios)
   - Do's/Don'ts = 20 límites cognitivos aplicados
   - Implementation guide = CaaS deployment guide

### Mode B: Marketing Asset Factory (Alráico-Enhanced) — **47+ Assets Alráicos**
**Inputs:** Campaign objective, target audience (demo + psycho), theme, tone
- **Ontológica**: ECROx audience (αʰ, s, y, v, XP, k)
- **Teleológica**: Assets como transductores F: {audience} → 𝕮 → {conversion}
- **Axiológica**: Resonancia αʰ_asset·αʰ_audience·3.0 > αʰ_asset+αʰ_audience

**Deliverables (47+ Assets Alráicos):**
1. **Digital Ads (15)** - Google, FB/IG, Display
   - Cada ad = transductor F: {audience_ECROx} → 𝕮 → {CTA}
   - Resonancia: αʰ_ad·αʰ_audience·3.0 > αʰ_ad+αʰ_audience
2. **Email Marketing (8)** - Subject lines, templates
   - Secuencia = tick Alráico (6 loops + γ-CARMIS + resonancia)
3. **Landing Page Copy (5)** - Hero, features, social proof, FAQ, pricing
   - Pricing = anfibio (ZNU/USDC via priceParity)
4. **Social Media (12)** - LinkedIn, X, IG, TikTok
   - Cada post = tick micro-Alráico
5. **Sales Enablement (7)** - One-pager, deck, case study, battlecard, demo, objections, proposal
   - Battlecard = análisis competitivo ECROx
6. **Content Marketing (5)** - Blog, whitepaper, webinar
   - Whitepaper = paper científico (hscsg-scientific-papers)

**Each Asset Includes (Alráico):**
- Exact copy + ECROx annotations
- Visual direction = αʰ visual harmony
- CTA = γ-CARMIS trigger (ΣPᵢ > κ → CTA)
- A/B test = γ-CARMIS experiment (ΣPᵢ > κ variant)
- Resonancia score = αʰ₁·αʰ₂·3.0 > αʰ₁+αʰ₂

### Legal/Sanitization Guide (Alráico)
- Maps proprietary terms → generic descriptive equivalents (transducción F)
- Separate sanitized version for public repos (anfibio)
- Original with proprietary terms kept local only (RAO local)
- **Transducción F**: {término_propietario} → 𝕮 → {equivalente_genérico}
