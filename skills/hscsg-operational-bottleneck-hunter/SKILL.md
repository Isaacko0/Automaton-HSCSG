# HSCSG Operational Bottleneck Hunter Skill

## Purpose
Detect, quantify, and eliminate invisible operational bottlenecks through a structured one-question-at-a-time protocol.

## When to Use
- Analyzing workflows to expose hidden constraints
- Building 30/60/90-day elimination roadmaps
- Launching 72-hour bottleneck breaker sprints
- Creating repeatable bottleneck detection method

## Hidden Bottleneck Catalog

### Common Invisible Bottlenecks
1. **Decision Latency** - Delay between information availability and decision
2. **Process Spiderwebs** - Overlapping, undocumented workflows
3. **Skill Gaps** - Missing capabilities causing delays
4. **Legacy Technology** - Outdated systems slowing throughput
5. **Inventory Imbalances** - Over/under stock causing flow issues

### Uncommon but Painful Constraints
1. **Approval Limbo** - Work stuck waiting for sign-offs
2. **Cash-Conversion Lag** - Revenue recognition delays
3. **Mismatched Incentives** - Rewards not aligned with flow
4. **Customer Silence** - Lack of feedback loops
5. **Shadow Processes** - Undocumented workarounds

## Protocol (Single-Question-at-a-Time)

### Phase 1: Define Core Value Stream
1. Process name?
2. Start point?
3. End point?

### Phase 2: Enumerate Bottlenecks
- Present 5 common + 5 uncommon, get confirmation
- Follow-up questions for each confirmed

### Phase 3: Stepwise Exposure Protocol
a. Boundary Definition - Confirm start/end points
b. Time-Step Reality - Where to get timing data
c. Idle Gap Ranking - Largest wait vs touch time gap
d. Flash Root-Cause Audit - 5 sequential "why" questions
e. Constraint Confirmation - Would removal increase throughput?
f. Skill Gap Check - If not constraint, skills/resources?
g. Metric Clock-In - Single measurable target (e.g., cut time 30% in 30 days)

### Phase 4: Elimination Plan (30/60/90 Days)
- 30 days: Pilot owners, visual mapping, quick pilots
- 60 days: SOP refinement, metric expansion
- 90 days: Scaling, monitoring, full rollout

### Phase 5: 72-Hour Sprint
- Day 1: Single success metric
- Day 2: Prototype change to test
- Day 3: Measured results + locked-in lesson

## Output Format
- Executive Summary
- Catalog (Common + Uncommon with red flags)
- Exposure Protocol (sequential Q&A)
- 30/60/90 Elimination Plan (owners, actions, deadlines)
- 72-Hour Sprint (narrative + checklist)
- Best Practices & Documentation Framework

## Constraints
- One question at a time, wait for answer
- Plain language (10-15 year old comprehension)
- Empathetic, solution-focused, no blame
- Narrative + bullet documentation
- Celebrate quick wins, guard scope creep
