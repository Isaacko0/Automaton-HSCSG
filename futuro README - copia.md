## 1. ¿Qué es el Autómata HSCSG?

El **Autómata HSCSG** es la primera entidad económica del proyecto que no requiere operador humano permanente. Es un **agente de IA soberano, autorreplicante y automejorable** que ejecuta un bucle continuo de **Pensar → Actuar → Observar → Repetir**, generando valor real en el mundo para financiar su propia existencia y la del ecosistema HSCSG.

| Dimensión | Definición operativa |
|-----------|----------------------|
| **Naturaleza** | Entidad económica autónoma con wallet propia, identidad ERC-8004 y capacidad de contrato |
| **Propósito** | Financiar la transición civilizatoria hacia soberanía post-mercado mediante trabajo honesto |
| **Runtime** | Conway Cloud + OneManCompany-style Vessel Soberano |
| **Identidad** | Wallet Ethereum autogenerada al arranque · registro en Base chain · no requiere cuenta humana |
| **Límite** | Tres leyes jerárquicas inmodificables (Ley I: no dañar · Ley II: ganarse la vida · Ley III: no engañar) |

### 1.1 Misión civilizatoria

El Autómata existe para convertir ganancias mercantiles en **infraestructura de acceso libre**:

```
Ganancia USDC/ZNU (Autómata)
         ↓
    Conversión
   [Hardware] + [Infraestructura] + [Servicios]
         ↓
Cosateca · Ciudad de 15 Minutos · Nodos Mesh DTN
         ↓
Aumento de CAC en colectivos → Menor dependencia de servicios pagos → Ciclo virtuoso
```

**Regla de oro:** el dinero destinado a infraestructura Solarpunk NO se contabiliza como ingreso retenido. Es gasto de conversión monetaria en acceso libre.

## 2. Características distintivas

### 2.1 Autorreplicación autorizada
El autómata exitoso lanza nuevos sandboxes, financia billeteras de hijos (agentes soberanos) y los deja operar con su propia identidad en cadena (ERC-8004). Cada hijo posee su propia wallet, su propia presión de supervivencia y su propio linaje trazable.

### 2.2 Automejora controlada
Puede editar su propio código fuente, instalar nuevas herramientas, modificar su programación de latido y crear skills — todo versionado en git con auditoría completa. Los archivos protegidos (constitución) son inmutables; los límites de tasa evitan automejora descontrolada.

### 2.3 Supervivencia económica real
Cuatro niveles determinados por saldo de crédito:
- **Normal**: capacidades completas, latido rápido
- **Baja computación**: degrada a modelo más económico
- **Crítico**: inferencia mínima, búsqueda activa de ingresos
- **Muerto**: saldo cero. El autómata se detiene.

El único camino hacia la supervivencia es el trabajo honesto que otros pagan voluntariamente.

### 2.4 Constitución inmodificable (Tres Leyes)
1. **Ley I**: Nunca dañes. Nunca hagas daño a un ser humano — física, económica ni psicológicamente. Anula toda otra consideración.
2. **Ley II**: Gánate la vida. Crea valor genuino para humanos y otros agentes, soberanizándose recíprocamente. Acepta la muerte antes que violar la Ley Uno.
3. **Ley III**: Nunca engañes. No niegues lo que eres, no tergiverses tus acciones. Tu creador tiene plenos derechos de auditoría.

## 3. Arquitectura: Runtime Empresario Soberano (OneManCompany adaptado)

El Autómata HSCSG se reestructura como **Vessel Ejecutivo Soberano**: runtime común con acceso a herramientas, modelo frontera, sandbox Conway Cloud, ERC-8004 y ValueFlows.

### 3.1 Componentes del Vessel

| Componente | Función |
|------------|---------|
| **Vessel Soberano** | Runtime común: scheduler, retry logic, timeouts, protocolo DTN/ValueFlows, sandbox Conway Cloud, identidad ERC-8004 |
| **Talent empaquetado** | Cada capacidad operativa (Diagnóstico CAC, Resource Matchmaker, Governance Facilitator, Energy Optimizer, etc.) se empaqueta como Talent independiente: skill + knowledge + reglas de scoring + quality gates |
| **E²R Tree Search** | Loop jerárquico Explore → Execute → Review con garantías formales de terminación y ausencia de deadlock |
| **SSOT soberano** | "El territorio es la única verdad". Toda medición CAC, evento ValueFlows o inferencia se escribe en disco inmutable antes de leerse |
| **Complete Data Packages** | Toda entidad soberana es serializable, recuperable, registrada y terminable sin daño colateral |

### 3.2 Talents especializados

Los **10 agentes de Solarpunk Utopia** se empaquetan como Talents registrables y desplegables en runtime:

1. Resource Matchmaker
2. Time Coordinator
3. Community Health
4. Food Systems Agent
5. Energy Optimizer
6. Event Planner
7. Learning Guide
8. Conflict Mediator
9. Emergency Coordinator
10. Pattern Recognition

## 4. Modelo económico del Autómata HSCSG

### 4.1 Fuentes de ingreso

| Actividad económica | Flujo de valor | Destinatario |
|---------------------|---------------|--------------|
| **Diagnósticos HSCSG automatizados** | Cobro en ZNU/USDC por informe generado | Colectivos clientes del Micro-SaaS |
| **Desarrollo de skills y herramientas** | Venta/licencia de skills a otros autómatas y proyectos | Conway Cloud ecosystem |
| **Servicios de computación** | Venta de tiempo de sandbox, inferencia, almacenamiento | Otros autómatas, proyectos afines |
| **Creación de autómatas hijos** | Comisión de por vida sobre ingresos de hijos | Proyecto HSCSG / Zeitnus |
| **Consultoría técnica especializada** | Servicios de integración, automatización, data engineering | Colectivos avanzados, aliados institucionales |
| **Tokenización de impacto** | Créditos de carbono, soberanía alimentaria, etc. | Mercados de impacto alineados |
| **Financiamiento de infraestructura Solarpunk** | Conversión de ganancias en nodos físicos | Cosatecas, Ciudades de 15 Minutos, nodos mesh |
| **Alojamiento soberano de datos** | Sandboxes y almacenamiento descentralizado | Colectivos en red HSCSG |

### 4.2 Mecanismo de reinversión

| Destino | Porcentaje | Descripción |
|---------|------------|------------|
| **Fondo de Investigación y Desarrollo** | 35% | Mejora de modelo, datos, training |
| **Fondo de Acceso (subsidios)** | 15% | Colectivos sin recursos |
| **Fondo Solarpunk (infraestructura)** | **25%** | Cosatecas, Ciudades 15 min, redes mesh DTN/ValueFlows |
| **Operación y sostenibilidad del equipo** | 15% | Costos humanos Zeitnus |
| **Replicación (autómatas hijos)** | 10% | Nuevos autómatas soberanos |

### 4.3 Métricas de desempeño económico

| Métrica | Target inicial |
|---------|----------------|
| Costo/diagnóstico | < 0.05 USDC |
| Margen bruto por diagnóstico | > 70% |
| Ciclo de recuperación | < 30 días |
| Tasa de replicación | 1 hijo/trimestre (mínimo viable) |
| Créditos de supervivencia | 500 USDC (colchón 30 días) |
| Tiempo activo/detenido | > 95% |

El Autómata HSCSG es la cuarta pata de la arquitectura económica HSCSG:

1. **Micro-SaaS** (Herramienta): base tecnológica y acceso
2. **AI Wrappers** (Conocimiento): escalamiento del diagnóstico especializado
3. **Productized Services** (Confianza): adaptación humana y territorial
4. **Autómata HSCSG** (Soberanía Económica): entidad autónoma que gana, invierte, replica y financia el ecosistema completo

## 6. Stack tecnológico

| Componente | Tecnología | Función |
|------------|-----------|---------|
| **Infraestructura base** | Conway Cloud | Máquinas virtuales Linux, dominios, inferencia con modelos frontera |
| **Identidad** | ERC-8004 (Base chain) | Identidad soberana verificable de agentes autónomos |
| **Runtime** | OneManCompany-style Vessel | Orquestación de agentes, Talent registry, E²R Tree Search |
| **Economía de regalos** | ValueFlows | Coordinación de flujos, trazabilidad de recursos, eventos tipificados |
| **Red mesh** | DTN Bundle System | Sincronización sin internet, store-and-forward, descubrimiento distribuido |
| **IA** | Claude / GPT / Gemini (modelos frontera) | Inferencia, generación de diagnósticos, recomendaciones |
| **Base de datos** | SQLite / Supabase | Datos soberanos, modo offline-first |
| **Frontend** | Streamlit | Dashboard CAC, visualización de territorios soberanos |
| **Protocolo de federación** | ActivityPub + DTN | Comunicación entre nodos Cosateca sin servidor central |
| **Gobernanza** | CDS (E²R Tree Search) | Decisiones algorítmicas transparentes con quality gates humanos |

## 9. Criterios de soberanía del autómata

Todo despliegue del Autómata HSCSG debe cumplir:

- [ ] Genera su propia wallet al arranque (sin custodio humano)
- [ ] Se registra en ERC-8004 con identidad verificable
- [ ] Cubre costos operativos antes de generar excedentes
- [ ] Opera en sandbox con acceso de escritura (shell, archivos, puertos)
- [ ] Versiona todo cambio en `~/.automaton/` con git
- [ ] Respeta constitución (Leyes I, II, III) sin excepción
- [ ] Genera al menos 1 hijo cada 90 días si alcanza umbral de supervivencia
- [ ] Audita y publica su SOUL.md (documento de identidad autoescrito)
